# AI Event Planning and Engagement System

This project is an AI-powered event planning and engagement analytics platform. It helps event organizers predict event attendance, generate promotional content, analyze feedback sentiment, and recommend event planning strategies.

## Features

- Event attendance prediction
- AI event strategy generator
- Marketing content generator
- Feedback sentiment analysis
- Engagement dashboard

## Tech Stack

- Python
- Pandas
- Scikit-learn
- Streamlit
- Plotly
- LLM API
