# AI Event Planning & Engagement System

An AI-powered event management platform designed to improve event planning, marketing, attendance prediction, and engagement using Machine Learning, NLP, analytics, and recommendation systems.

## Features

### Attendance Predictor

Machine learning powered attendance prediction using event attributes.

### AI Event Planner

Generate event planning strategies using AI recommendations.

### Marketing Generator

Create AI-generated promotional event content.

### Feedback Analyzer

NLP sentiment analysis using TextBlob.

### Analytics Dashboard

Interactive visual analytics and engagement insights.

### AI Recommendations

Optimization recommendations using historical event data.

### Event History

Persistent event storage using SQLite.

## Overview

The AI Event Planning & Engagement System is a smart event management application built using Python and Streamlit.

The platform helps users:

* Predict attendance
* Generate AI-powered event strategies
* Create marketing content
* Analyze attendee feedback
* View analytics dashboards
* Store historical event data
* Generate planning recommendations

The project demonstrates practical AI engineering and product design skills.

## Installation

Clone repository:

```bash
git clone https://github.com/OmkarK23/ai-event-planner.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
streamlit run app/main.py
```
